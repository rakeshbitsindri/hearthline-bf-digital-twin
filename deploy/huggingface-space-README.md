# Hearthline: blast furnace advisory digital twin

Read only advisory digital twin for iron blast furnaces. Reduced order physics (RAFT, Rist, Ergun), sensor reconciliation, a walk forward learned layer, production conditioned Golden Ranges, and backward compatible production shortfall root cause attribution.

Running on the EVRAZ ZSMK public reference series (2013 to 2016). This is a public reference furnace, not a specific plant, and it is not live. Every screen labels evidence class and capability status.
