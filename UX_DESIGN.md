Industrial night shift, not a marketing page. Warm black `#14120e`, paper text `#efe6d6`, heat `#e07a3d`, gas `#8fbfb6`, fault `#d85a3a`. Display face: Fraunces. UI face: Outfit. Numbers: IBM Plex Mono.

Four workspaces: Observe, Investigate, Decide, Govern. The public-reference banner stays visible. Every value has an evidence class. The furnace section is an SVG cross-section with the ten peripheral probes in index order, because angles were not in the file. A situational sketch sits beside it and is labelled as not a measured profile.

States: loading, ready, not_testable, not_run, not_identified. Stale is not used on this static file. The clock always shows the selected historical hour.
