# Public reference data

Files here are published datasets used to build the software. They are not the plant's historian.

| Folder | What it is |
|---|---|
| [evraz-zsmk-2013-2016/](evraz-zsmk-2013-2016/) | Hourly blast-furnace sensors, EVRAZ ZSMK, 2013–2016. CC BY 4.0. Read `PROFILE.md` before using it in a model. |

Do not add electric-arc, casting, or steel-plant electricity files to this folder and call them blast-furnace history. Do not add the Zhejiang University ironmaking repository without its research-only notice, and do not mix it into the EVRAZ furnace.
